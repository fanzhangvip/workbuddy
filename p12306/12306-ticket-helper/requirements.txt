#   ↑ `pip install PySide6` 会同时装 Essentials + Addons。
#
# 实时通道（桌面端「已连接（WebSocket）」）——**容易漏**：
# QtWebSockets **不在 PySide6-Essentials 里**，它在 PySide6-Addons 里。
# 只装了 Essentials 时，桌面端会静默降级为轮询（功能不受影响，延迟约 2 秒），
# 状态栏显示「轮询模式（未安装 QtWebSockets）」。
#   pip install PySide6-Addons          # 版本要与 PySide6 严格一致，例如 ==6.11.2
# 校验：python main.py doctor  → 应出现
#   [√] 实时通道  WebSocket 推送可用（QtWebSockets 已就绪）
#
# 注意两点：
#   1) QtWebSockets 依赖 PySide6.QtNetwork，打包时两者都要在 hiddenimports 里，
#      且**不能**把 PySide6.QtNetwork 放进 excludes（会报
#      "libshiboken: could not import module 'PySide6.QtNetwork'"）。
#   2) Addons 整包约 500MB，但本项目只需要 4 个文件（约 400KB）：
#      Qt6WebSockets.dll / QtWebSockets.pyd / QtWebSockets.pyi /
#      metatypes/qt6websockets_metatypes.json
#      —— 离线环境可以只解压这几个文件到 site-packages/PySide6/。
