账号管理

先登录一个 12306 账号

抢票必须用你自己的 12306 账号。扫码登录是唯一可靠的路径 —— 密码登录目前会被官方风控挡住。登录成功后会把这个账号的会话加密记住， 重启程序通常不需要重新扫。

密码使用本机密钥加密后存入 SQLite，不回显、不写入日志。 扫码登录创建的账号不保存密码，但会把登录会话加密记住， 所以正常情况下重启后不必重新扫码；会话过期时才需要再扫一次。

人证核验怎么做？（候补购票的前置条件）

12306 规定：申请候补购票前需完成人证一致性核验。 已通过核验的账号、以及已激活的「铁路畅行」会员自动满足该条件。 核验要人脸识别，必须本人在手机上做，程序不能代做。

  1. 手机上打开「铁路 12306」App（未安装请到应用商店搜索安装，认准官方）
  2. 登录账号，点右下角「我的」
  3. 在名字下方找到「人证核验」，点进去
  4. 勾选同意后点「开始核验」，按提示做人脸识别
  5. 核验通过后回到本页面，点该行账号的「重测核验」刷新状态

官方说明：铁路互联网购票身份信息核验问答
