## 实现中发现并修复的真实缺陷（容易复发的坑）

| 问题 | 结论 |
|---|---|
| secretStr 里塞了 `|` 会破坏定长字段协议 | 余票行 index 0 是 secretStr（不含 `|`），index 2 才是内部车次号 train_no |
| 席别优先级会「顺带」下单未配置的席别 | `available_seats(priority)` 必须**严格**只返回配置内的席别 |
| 风控降级会被后续逻辑覆盖成 error | `login()` 失败收尾时不得覆盖已判定的 RISK 状态 |
| 已禁用的账号因残留会话仍可被使用 | `login()` 必须先判 enabled 再走「已登录直接返回」 |
| HTTP 429 被当作普通网络错误 | 429/403 必须抛 `RiskControlError`，否则限速器学不到信号 |
| 查询引擎把风控/掉线当局部错误吞掉 | `LoginError`/`RiskControlError` 必须向上抛，其余按组合吞掉 |
| 排队超时被误报为「失败」 | 新增 `timeout` 语义 → 标记为排队中待人工确认，绝不误报失败 |
| 下单失败候选被**永久**拉黑 | 改为 30s 冷却（`FAILED_CANDIDATE_COOLDOWN`），否则「有票也不再抢」 |
| 停止流程里取不到账号 → 候补单取消不掉 | `_resolve_user(ignore_stop=True)` 用于 stop 路径 |
| 模板占位符被当成真实后台密码 | 用正则替换 `auth_pass`；**全星号一律视为未设置**并重新生成 |
| 人工验证码兜底不可达 | `ManualSolver` 需要 `enable_pull()` 武装（有 Web 界面时才开） |
| 账号离线时启动任务只会空等 | `AppContext._provide_account` 兜底补登录（20s 冷却） |
| `@guard` 在导入期解析 TokenManager | 装饰器必须**请求时**再取依赖，否则模块导入即崩 |
| `/api/internal/ping` 文档说本机可调但实际没限制 | 补 `@require_internal()` |

## PyInstaller 打包踩坑

- `SPECPATH` 就是 spec 所在目录（项目根），**不要再取 `.parent`**。
- `version=` 需要**文件路径**，不能直接传字符串（否则报 Invalid argument）。
- ICO 用「一张基础图 + `sizes=[...]`」保存；用 `append_images` 只会保留 16x16 一帧。
- 不要启用 UPX（抢票类工具误报率会明显上升）。
