图 3 · 回写 outbox 状态机

分数回写与等级标签是两条完全独立的链路：表、开关、水位互不共享。

stateDiagram-v2 [*] --> pending: 与 assessment 同事务入队 pending --> sending: _claim + FOR UPDATE SKIP LOCKED sending --> done: errcode == 0 → 推进水位 sending --> failed: 失败 → 退避 30s→3600s failed --> sending: next_attempt_at 到期 failed --> dead: attempts ≥ 8 → 待人工 done --> [*]
分数 差值累加 · writeback_ledger · 开关 score_writeback_mode（默认 dry_run） 等级 标签覆盖 · grade_tag_ledger · 开关 grade_tag_mode（默认 off） 卡死回收 sending 超 600s 回退为 failed
