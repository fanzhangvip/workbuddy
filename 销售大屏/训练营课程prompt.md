# 训练营课程提示词

## 第一节课
> 工具: Workbuddy

### 准备工作
1. 打开WorkBuddy
2. 新建一个任务
3. 选择代码开发
4. 点击“+”号， 选择模式，然后打开计划开关

### 提示词
#### 定义身份
```text
你是一名Python全栈开发工程师，熟悉Pandas(数据分析) flask, JavaScript和echarts
```

```text
接下来采用增量开发模式，每次只完成当前功能，不提前开发后续内容，不重写已经能运行的代码，代码要简单，并且要添加必要的注释 
```

```text
在当前目录下，生成一个flask项目框架，其他不做任何改变
```

#### 让WorkBuddy启动项目
```text
帮我启动项目
```

#### 生成销售数据表
```text
生成一个模拟的销售数据表，共300条，字段包含： 日期，省份，产品(美妆产品)，渠道，销量，销售额， 利润。 保存到data/data.csv。 其中省份尽量多些
```

#### 生成销售大屏
```text
后端实现flask已经开发好的框架，前端使用HTML，CSS，JavaScript，echarts制作黑色商业风格的数据大屏。使用数据表里面的表头数据制作三栏销售可视化大屏，两侧展示销售明细，地区占比，产品排行，渠道占比，利润进度和地区热榜。顶部展示核心指标，中间展示中国销售地图和月度趋势。采用浅蓝色商业风格，白色卡片，蓝色渐变和玻璃质感，加入数字滚动，列表自动轮播，图标动态切换，地图涟漪，进度动画和定时数据刷新，鼠标悬停时暂停滚动。适配1920*1080
```

## 第二节课

#### 1. 增加CSV数据管理
```text
先检查当前Flask项目和CSV文件能否正常使用，如果发现问题先修复
然后增加一个数据管理后台，支撑查看CSV信息(文件名 文件大学，字段完整性) 预览数据 上次新文件，覆盖和删除文件。
上传时检查是否包含日期，省份，产品，渠道，销量，销售额和利润自动。删除CSV后，大屏显示暂无数据，重新上传后恢复正常。
```

#### 2.  接入deepseek数据分析师
```text
接入deepseek模型:
API Key: 
模型： deepseek-v4-flash
接口：https://api.deepseek.com
使用LangChain的create_agent创建AI数据分析师，并为它提供一个Pandas数据查询工具。
工具可以按日期，省份，产品和渠道查询数据，并完成销量，销售额 利润和利润率的统计，排名，对比及趋势分析。
只要用户询问数据，deepseek必须先调用工具，在根据真实结果回答。不能执行任意代码，也不能猜测和编造数据；数据不足时要直接说明。
数据分析师的角色定义提示词该怎么写
```

#### 3. 增加AI悬浮机器人
```text
在原销售大屏右下角增加一个AI悬浮机器人。
机器人支持打开，最小化，输入问题，发送消息，加载提示和消息滚动。
用户提问后，机器人调用AI数据分析师，并显示简短结论，关键数据依据和实际使用的Pandas工具。
没有CSV时不能分析数据；普通文化不调用工具；AI只能读取和分析数据，不能修改原大屏和CSV。
```
