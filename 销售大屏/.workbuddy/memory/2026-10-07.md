## 踩坑记录：curl 检查接口时的假 502

- 沙箱环境设置了 `http_proxy=http://127.0.0.1:60447`，且 Git Bash 会把 url 里的路径反斜杠/前导斜杠做 MSYS 路径转换。
- 现象：用 `curl -w "/$p HTTP=%{http_code}"` 这类带前导斜杠的格式串时，
  输出被打成 `C:/WorkBuddy/resources/vendor/PortableGit/health` 之类的怪路径，且拿到假的 502。
- 正确做法：检查本机接口前先 `export MSYS_NO_PATHCONV=1`，且 `-w` 格式串不要以 `/` 开头；
  遇到可疑状态码时用 `netstat`/进程列表交叉验证，避免误判服务没起来。
