# 美妆销售数据可视化大屏

基于 **Flask + Pandas + 原生 JS + ECharts** 的三栏式销售数据大屏，黑色钻石商业风格，
固定 1920×1080 设计并支持等比缩放适配其他分辨率。

## 快速开始

```bash
# 1. 安装依赖（已在项目虚拟环境中安装好，此步可跳过）
pip install -r requirements.txt

# 2. 若还没有数据，先生成一份模拟数据（300 条美妆销售记录）
python -m core.mock_data

# 3. 启动服务
python app.py
```

浏览器打开 <http://127.0.0.1:5000> 即可。

- **大屏**：<http://127.0.0.1:5000>
- **数据管理后台**：<http://127.0.0.1:5000/admin>
- **AI 数据分析师**：<http://127.0.0.1:5000/analyst>

> Windows 下虚拟环境路径：`C:\Users\Admin\.workbuddy\binaries\python\envs\default\Scripts\python.exe`

## 对接你的真实数据

有两种方式，任选一种。

### 方式一：数据管理后台（推荐）

打开 <http://127.0.0.1:5000/admin>：

| 功能 | 说明 |
|---|---|
| 文件信息 | 文件名、文件大小、数据行数、字段数量、修改/上传时间 |
| 字段完整性校验 | 逐项打勾/打叉检查 7 个必需字段 |
| 数据预览 | 表格预览前 15 行 |
| 上传并覆盖 | 支持 CSV / XLSX / XLS，**上传前自动校验必需字段** |
| 删除数据文件 | 删除后大屏显示「暂无数据」 |

**上传校验规则**：文件必须包含全部 7 个字段 —— 日期、省份、产品、渠道、销量、销售额、利润。
缺任何一个都会被拒绝，并明确提示缺了哪些字段，**且不会破坏现有数据**。

上传成功后大屏会自动更新（切回大屏标签页即刻刷新，空态下每 10 秒轮询一次）。

### 方式二：直接替换文件

把你的表格另存为 `data/data.csv`，表头保持这 7 列：

| 列名 | 类型 | 说明 |
|---|---|---|
| 日期 | 日期 | 如 `2026-09-01` |
| 省份 | 文本 | 省份名，用短名（`广东` / `内蒙古` / `西藏`） |
| 产品 | 文本 | 商品/品类名 |
| 渠道 | 文本 | 销售渠道 |
| 销量 | 数值 | |
| 销售额 | 数值 | |
| 利润 | 数值 | |

> 省份用短名是为了和 ECharts 中国地图命名对齐。若你的数据是「广东省」这类全名，
> 把 `static/js/charts.js` 里的 `toFullName()` 改为直接返回原名即可。

**改列名映射**：若你的表头不同，修改 `core/loader.py` 顶部的 `REQUIRED_COLUMNS`，
或在读取后重命名列。

**调整指标口径**：`core/analytics.py` 中每个函数对应一块图表，改起来互不影响。

## AI 数据分析师

基于 **LangChain `create_agent` + DeepSeek** 的自然语言数据分析问答。有两个入口：

| 入口 | 位置 | 形态 |
|---|---|---|
| **悬浮机器人** | 大屏右下角 🤖 圆球 | 轻量浮窗，返回「结论 + 依据 + Pandas 操作」 |
| **完整问答页** | <http://127.0.0.1:5000/analyst> | 独立页面，Markdown 富文本回答 |

### 配置

密钥放在项目根目录的 `.env`（已被 `.gitignore` 排除，不会进版本库）：

```
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
```

改完 `.env` 需**重启服务**生效。

### 右下角悬浮机器人

大屏右下角的 🤖 圆球，点开即用。支持**打开 / 最小化 / 输入提问 / 发送 / 加载提示 / 消息滚动**。

每次回答按三段展示：

1. **结论** —— 一句话结论，必含具体数字
2. **关键数据依据** —— 支撑结论的数据点
3. **实际执行的 Pandas 操作** —— 例如
   `df.groupby('渠道').agg({'销量':'sum','销售额':'sum','利润':'sum'}).sort_values('利润', ascending=False).head(10)`

> 第 3 条不是模型自述，而是**工具执行时回传的真实表达式**（LangChain 的 `content_and_artifact`），
> 可通过 `core/analyst_tools.py` 中的实现逐字核对。

**行为约束**

| 场景 | 表现 |
|---|---|
| 问数据 | 先调工具，再给三段式回答 |
| 打招呼 / 闲聊 | **不调用工具**，直接一段话回复，不显示依据与 Pandas 块 |
| 没有 CSV | 明确回复「无法分析」并提示去数据管理后台上传，**不编造数字** |
| 数据查不到 | 直接说明查不到，并给出实际可用的取值范围 |

### 它怎么保证不编造数据

这是本功能的核心设计，分三层：

1. **只能通过工具取数**。模型仅被授予一个工具 `query_sales_data`，
   该工具**只接受结构化参数**（维度 / 指标 / 筛选条件 / 分析类型），
   不接受任何代码字符串 —— 因此模型**无法执行任意代码**，也无法绕开受限查询直接读文件。
2. **提示词强制先查后答**。系统提示明确要求：涉及数据的问题必须先调用工具；
   不确定有哪些省份/产品/渠道时，先查 `options` 再查数据；查不到就直接说查不到。
3. **答案可核对**。悬浮机器人会显示实际执行的 Pandas 表达式，
   完整问答页会显示工具调用轨迹（调了什么工具、传了什么参数）。

### 权限边界：AI 只能读，不能写

AI 的**唯一**数据入口是 `core/analyst_tools.py` 里的 `query_sales_data`，
该文件**不含任何写操作**——没有写文件、删文件、改数据的代码路径。
因此 AI 在架构上就不可能修改 `data/data.csv`，也不可能改动大屏的图表或页面内容
（它没有对应的工具，也没有访问前端的能力）。系统提示词另有明文约束，但真正的保障是"没有这个能力"。

### 工具能力

`query_sales_data` 支持：

| 参数 | 取值 |
|---|---|
| `analysis` | `summary` 统计 / `rank` 排名 / `compare` 对比 / `trend` 趋势 / `options` 查可选取值 |
| `metric` | 销量 / 销售额 / 利润 / 利润率 |
| `dimension` | 省份 / 产品 / 渠道 / 日期 / 月份 / 季度 / 年度 |
| 筛选 | `start_date`、`end_date`、`provinces`、`products`、`channels`（多个用逗号分隔） |
| `top_n` | 排名/对比返回条数，默认 10，上限 50 |

### 可以这样问

- 各省份销售额排名前五是谁？
- 抖音直播间的销售额和利润率是多少？
- 按月看销售额趋势，哪个月最低？
- 浙江和广东的销售额对比一下
- 哪个产品的利润最高？

### 注意事项

- 该模型带**推理过程**，回答需要几秒到几十秒，且会消耗较多 token。
- 密钥以明文存放于 `.env`，请勿提交或外传；如怀疑泄露，请到 DeepSeek 控制台重置。

## 说明与注意事项

- **数据缓存**：`core/loader.py` 按文件修改时间缓存。通过管理后台上传/删除后会自动清缓存，
  大屏下次请求即可读到新数据。
- **暂无数据状态**：数据文件不存在、或字段不完整导致无法解析时，`/api/dashboard` 返回
  `empty: true` 而**不报错**，大屏显示「暂无数据」遮罩并提供跳转后台的入口。
- **上传留档**：每次上传的原始文件会另存一份到 `data/uploads/`，便于追溯。
  来源文件名与上传时间记录在 `data/.meta.json`。
- **文件占用**：若 `data/data.csv` 正在 Excel 中打开，覆盖/删除会提示“文件被占用”，
  关闭 Excel 后重试即可。
- **地图合规**：使用符合国家测绘标准的中国地图数据，含台湾省、香港、澳门特别行政区
  及南海诸岛（九段线），地图数据在 `static/lib/china.json`。
- **离线可用**：ECharts 与地图数据均本地内置，不依赖外网 CDN。
- **开发服务器**：`python app.py` 启动的是 Flask 开发服务器，仅适合本机调试。
  若要局域网/生产部署，请改用 waitress 等 WSGI 服务器并调整 `config.py` 的 `HOST`。
  ⚠️ 开发模式下改后端路由/配置后**热重载可能不生效，建议手动重启服务**。
- **配色约定**：遵循国内习惯，涨为红、跌为绿。
