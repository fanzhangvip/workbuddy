## 环境踩坑（重要，后续复用）

- `setup-html-to-docx.sh` 在 Windows 上会误判依赖已装齐（脚本检查 `$VENV_DIR/bin/python`，但 Windows venv 实际是 `Scripts/python.exe`），导致 `import click` 失败。
- 修复命令：
  `export PATH="$HOME/.local/bin:$PATH"; uv pip install --python "/c/Users/EDY/.venv-html-to-docx/Scripts/python.exe" --only-binary=:all: -r <plugin>/skills/html-to-docx/scripts/requirements.txt`
- 之后调用：`cd <plugin>/skills/html-to-docx/scripts && "/c/Users/EDY/.venv-html-to-docx/Scripts/python.exe" -m html_to_docx convert in.html -o out.docx`
