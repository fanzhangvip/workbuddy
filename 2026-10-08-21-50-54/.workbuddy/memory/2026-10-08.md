**核心结论（分层定位，四者不是竞品）**
- MCP：工具/数据接入层（纵向）。Anthropic 2024-11 → AAIF 创始项目。2026-07-28 规范是史上最大修订：改无状态（去 initialize 握手与 Mcp-Session-Id）、请求经 `_meta` 自描述、`Mcp-Method`/`Mcp-Name` 头部路由、MRTR 替代长连接 elicitation、list 结果可缓存、CIMD 取代 DCR、Extensions 框架（Tasks/MCP Apps/EMA）+ 12 个月弃用窗口。生态 1 万+ Server，首年 40+ CVE 与"工具投毒"。
- A2A：Agent 横向协作层。Google 2025-04 → 2026-08 加入 AAIF。五对象模型（Agent Card / Task / Message·Part / Artifact / PushNotificationConfig）；九态任务状态机，终态不可重启；v1.0（2026-03）关键增量是签名 Agent Card（JWS + JCS）、多租户、多协议绑定、版本协商。生态 150+ 组织，生产案例 PayPal/Google ADK/Azure AI Foundry/AWS Bedrock AgentCore。
- ANP：开放互联网 Agent 互联。国内 ANP 开源社区，MIT。三层：DID `did:wba` + ECDHE 端到端加密 / 元协议协商层（自然语言协商后生成代码）/ ADP 描述 + 发现协议（JSON-LD）。押注"开放互联网"前提，生态早期。
- Agora：牛津大学 2024-10 元协议（arXiv:2410.11905）。Agent 通信三难困境（通用性/效率/可移植性）；协商三步 → Protocol Document（SHA1 标识）→ 编译成代码例程。概念验证，无主流实现。注意同名排雷：声网 Agora、npm `agora-protocol`（多智能体投票/否决语义）、npm `@rookdaemon/agora`。

## 追加：AG-UI 协议（同日）

**产出**：文档已增量扩写为 `智能体协议详解_MCP_A2A_ANP_Agora_AG-UI.html`（原文件名重命名；新增第 06 节 AG-UI 正文 + 分层图加"用户交互层" + 对比表加第 5 列 + 怎么选加第 5 问 + 误区扩到 7 条 + 术语表/参考资料同步）

**AG-UI 要点**
- Agent-User Interaction Protocol，CopilotKit 创建，2025-05 发布，MIT，仓库 `ag-ui-protocol/ag-ui`。定义 Agent 后端 ↔ 用户界面之间的**双向事件流**，是第三条轴（面向用户），与 MCP/A2A 互补。
- 单一核心抽象：`run(input) -> Observable<BaseEvent>`；事件仅 `type`(必填)/`timestamp?`/`rawEvent?`；传输无关（SSE / WebSocket / webhook）；中间件适配层，框架原生事件做适配即可接入。
- 事件族 7 类约 30 个：Lifecycle / Text / Tool Calls / State / Activity / Reasoning / Special。硬规则：run 必以 RUN_STARTED 始、RUN_FINISHED 或 RUN_ERROR 终；STATE_DELTA 用 RFC 6902 JSON Patch；CHUNK 类事件由 `transformChunks` 自动展开。
- **人在环中**为协议级：RUN_FINISHED 的 `outcome` 是判别联合（省略=未采用中断感知 / success / interrupt+interrupts[]）；恢复方式是发**新 run** 带 `resume` —— 不破坏无状态性，与 MCP 2026 的 MRTR 是同一思路。
- 1.0：规范冻结 + JSON Schema；TS/Python/.NET SDK 由 schema 生成；每条规则标注责任方（生产者/消费者）；向后兼容。生态：Google/Microsoft/Amazon/Oracle 采用；30+ 框架与前端运行时支持。
- 坑：取消语义不完整（无 `cancelled`，客户端断连被当外部取消）；治理由 CopilotKit 主导（集中度高于 MCP/A2A）；与 MCP Apps 有重叠（UI 所有权决定选型）。
- **易混**：AG-UI（线协议=管道）≠ A2UI（Google 的声明式 UI 载荷格式=管道里流的东西）。A2UI 载荷可经 AG-UI 或 A2A 传输。
