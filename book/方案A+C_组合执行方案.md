# 方案 A+C 组合执行方案

策划：阿客实验室 · 庄成卷
日期：2026-10-12
适用：《一个人的AI团队》行业工作流丛书（A）+《一小时看懂：AI+行业》品牌轻书丛书（C）

---

## 一、为什么 A+C 是最好的配对

| | 方案A《一个人的AI团队》 | 方案C《一小时看懂》 |
|---|---|---|
| 角色 | **深度主销书** | **广度引流书** |
| 读者拿到什么 | 一套能落地的工作流，照着做就能用 | 一张行业AI认知地图，知道风险与机会 |
| 单本字数 | 6–8 万字 | 3–4 万字 |
| 成书周期 | 6–8 周 | 2–3 周 |
| 品牌作用 | 证明"这家机构真懂行业" | 证明"这家机构一直在输出" |
| 销量角色 | 走量 + 高客单 | 铺量 + 低成本获客 |

**组合逻辑是一条三级漏斗：**

```
C 轻书（29–39元，广触达）
      ↓ 读者觉得"讲得清楚、有洞察"
A 工作流书（59–79元，深转化）
      ↓ 读者想"我还能做得更深"
你们的课程（高客单）
```

**关键设计：一个行业 = 一个"行业包"（1 本 C + 1 本 A）。**
同一个行业，同一批案例、同一套数据、同一位作者署名——**一套素材做两本书**。C 是 A 的"预告片"，A 是 C 的"完整版"。这是成书速度翻倍的核心。

---

## 二、丛书统一体例（这是"快速成书"的底层保障）

两套书都用**固定骨架**写，作者只填内容、不设计结构。这是产能的关键。

### A 系列骨架（12 章）

```
第1章   先看结果：AI在这个行业能替你做什么（3个场景对比）
第2章   上手准备：30分钟把工具配好
第3章   第一个交付物：最简单的那个，1小时出成果
第4–7章 主线项目：一步步做出「XX助手」（每章一个环节）
第8章   把项目变成日常工作流
第9章   常见坑与翻车现场
第10章  把AI变成日常习惯（一周工作流清单）
第11章  进阶方向 + 后续书与课程（引流位）
第12章  附录（可复制模板 / 速查 / 术语表）
```

### C 系列骨架（8 章）

```
第1章  三分钟看清：AI在这个行业已经做到什么程度
第2章  被改掉的岗位和被创造的岗位
第3章  <行业主角>的一天：AI能接走哪几件事
第4章  需求侧：客户/用户侧发生了什么变化
第5章  组织侧：从"买工具"到"改流程"
第6章  三个真实案例拆解（脱敏）
第7章  风险清单
第8章  你该怎么办：三种人的三种选择
附录   一页纸行业AI工具地图
```

### 视觉与版式（建议）

- **A 系列**：25开或16开，双色印刷，每章开头有"本章你会得到什么"色块；大量流程图 + 操作截图；附录模板用可撕式排版
- **C 系列**：小32开口袋书感，单色 + 一个主色，每章配一张信息图；**封面用"行业图标 + 一句话钩子"的极简体系**，10本放在一起要像一套
- **两系列必须一眼看出是一家**：统一的丛书标识、统一的字体、统一的章节起始页样式

## 四、出版节奏（三阶段）

| 阶段 | 时间 | 动作 | 产出 |
|---|---|---|---|
| **阶段一 试点** | 第 1–2 个月 | 出**教育行业包**：C01 先行（2–3周）→ A01 跟上（8–10周，含调研） | 2 本，验证市场反应 |
| **阶段二 铺开** | 第 3–6 个月 | C 系列再出 4 本（HR方向/电商/金融/政务）；A 系列再出 2 本（A02、A03） | 累计 8 本 |
| **阶段三 规模化** | 第 7–12 个月 | 补齐 C 系列至 10 本，A 系列至 6–8 本 | 累计 16–18 本 |

**试点期的验证指标**（用来决定后面怎么铺）：
- C01 的自然销量与传播（公众号/社群转化率）
- A01 的读者读完率（哪几章被翻烂、哪几章没人看）
- **哪个行业书带来最多课程咨询** —— 这个指标比销量更重要，直接决定后续优先级

> **提醒**：不要在阶段一同时开 3 本以上。C 系列快，可以并行 2–3 本；**A 系列必须一本一本做透**，因为每本都要跑真实流程、拍实操截图，赶工出来的书没有口碑。

## 五、素材盘点（重要：先把家底说清楚）

我逐条核对了课程大纲，A 系列的素材成熟度差异很大，先给你一张底牌：

| 素材 | 在大纲里的位置 | 可用于 | 可用度 |
|---|---|---|---|
| L1「行业AI提效实景」8大行业 | 第76–100行 | **每本A书的第1章**（痛点锚点） | 只有2行/行业，只能当框架 |
| L1「Skills实战」7个工具 | 第68–75行 | A书第2/3/8章（海报、PPT、数据分析、周报、本地知识库） | ✅ 可直接改造 |
| L1「AI学习助手V1.0」 | 第101–114行 | A书第6/7章（知识库、工作流设计） | ✅ 可改造 |
| HR 智能体平台全案 | 第1228–1274行 | **A02 全书主线** | ✅ 完整 |
| 电商订单 Copilot 全案 | 第1153–1227行 | **A03 全书主线** | ✅ 完整 |
| 医学智能客服 Agent | 第1433行起 | **A08 全书主线** | ✅ 完整 |
| 求职助手项目 | 第1549行起 | **A07 全书主线** | ✅ 完整 |
| **教育：Vibe Coding → SDD** | 第1275–1432行 | ⚠️ **与 A01 无关** | 面向开发工程师，不是老师 |

**结论（必须知道）：**

1. **A01《老师的AI助教》有约 60% 要新写。** 课程里的"教育"项目是"用AI开发教育产品"（技术向），不是"老师用AI备课"。大纲只提供了 2 行痛点。
2. **但这不一定是坏事**——A01 的新写内容恰好是你们最擅长的：让教研团队**真实跑一遍**备课、出题、批改、学情分析的完整流程，录屏 + 截图，这就是最真实、最有说服力的一手素材，市面上没有任何一本教育AI书有。
3. **A02/A03/A07/A08 反而好写**（有完整课程案例），**所以如果 6 个月内要快速起量，A02、A03 比 A01 更快**。但 A01 打头是对的——教育是你们主场，第一本必须打自己的招牌。
