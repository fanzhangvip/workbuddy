# 项目长期记忆 · 教研培训机构品牌书系列

## 项目背景

为「大模型培训教研机构」策划出版系列图书，目标：提升品牌效应。两个系列：
- **A 系列《一个人的AI团队》**：行业工作流丛书，8 本，每本一个行业，6–8 万字/本，12 章
- **C 系列《一小时看懂：AI+行业》**：品牌轻书，10 本，3–4 万字/本，8 章
- 组合逻辑：一个行业 = 1 本 C 轻书 + 1 本 A 工作流书，同素材同案例；三级漏斗 C(引流) → A(转化) → 课程(高客单)
- 首发：A01《老师的AI助教》→ C01（教育分册）

## 核心写作规范（务必遵守）

### 单章六段骨架（全书统一，是产能关键）
`钩子 → 本章论点 → 为什么 → 怎么做 → 案例(含踩坑) → 小结+衔接`
字数配比：钩子 6% / 论点 5% / 为什么 12% / 怎么做 55% / 案例 17% / 小结衔接 5%

### 三层内在联系
- 章内：六段是一条因果链，不是并列要点
- 章间：章末必须"交棒"，检验法——对调任意两章应觉得别扭
- 全书：一条主线贯穿（A01 = 一位老师的一学期工作流改造）

### 去 AI 味规范（融合 training-deai + humanizer-zh）
- 铁律：**保真 > 去味**，绝不编造数字/案例，缺数据写 `【待补：…】`
- 改写六步顺序**不能变**：L1 结构 → L5 信息 → L4 语气 → L2 句式 → L3 词汇 → 保真核对
- **L3 词汇放最后**——先换同义词是最常见的失败做法
- 阈值：A 系列 AI 味指数 < 25；C 系列 < 20

## 踩过的坑与约定

- **跑 AI 味检测必须只喂正文**（不含说明/附录/元信息），否则分数失真（曾误报"0 分"）
- 检测脚本：`C:/Users/EDY/.workbuddy/skills/training-deai/scripts/ai_flavor_detector.py`（用 managed python 3.13.12 跑）
- 判定"看着像 AI 味其实要保留"的通用问法：**删掉这段，读者会少知道一件事吗？会 → 保留**
- 语域：**A 系列 = 一位教了十几年的老师跟你聊天**；C 系列 = 行业观察者讲解。禁止网络流行语、"宝子们"、感叹号连用
- **不要让技术团队写 A01**——语气必须来自课堂，不是实验室
